- (capability) CAP-1 Guest browsing (FR-1): guests read profiles, reviews, albums, songs; write actions prompt sign-up/login
- (capability) CAP-2 Account creation and login/logout (FR-2)
- (capability) CAP-3 Staff catalog management (FR-3): create/edit/hide albums, songs, genre list; never delete
- (capability) CAP-4 Catalog search (FR-4)
- (capability) CAP-5 Log and rate album (FR-5): 0-5 half-star; album score = the Log; deletable
- (capability) CAP-6 Rate individual songs (FR-6): independent of album score; no computed album score
- (capability) CAP-7 Review album (FR-7): edit/delete own
- (capability) CAP-8 Listenlist (FR-8): add/remove; logging removes; logged album cannot be added; public
- (capability) CAP-9 Follow/unfollow, followers/following lists (FR-9)
- (capability) CAP-10 Feed (FR-10): followed users' recent album/song ratings, newest first
- (capability) CAP-11 Profile content (FR-11) and favorite genres from staff-managed list (FR-12)
- (capability) CAP-12 Favorites (FR-13): 5 albums + 5 songs, ordered, rating not required
- (capability) CAP-13 Public profile view (FR-14): picture, cover, bio, genres, favorites, recent ratings/reviews, visible to guests
- (constraint) Rating scale 0-5 in 0.5 steps; out-of-range/off-step rejected (FR-5, AD-5)
- (constraint) Catalog entities never hard-deleted so ratings, reviews, listenlists, favorites stay valid (FR-3, AD-12)
- (constraint) All profiles and listenlists public in MVP (PRD 4.7)
