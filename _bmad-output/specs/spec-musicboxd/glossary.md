# Musicboxd Glossary

- **User** — person with an account; can follow and be followed.
- **Guest** — visitor without an account; read-only.
- **Staff** — privileged User role managing the Catalog (create, edit, hide; no delete) and the genre list.
- **Catalog** — Albums and Songs available to log; filled manually by Staff.
- **Album** — release in the Catalog with one or more Songs.
- **Song** — track belonging to an Album.
- **Log** — a User's record of having listened to an Album. Not a separate record: an Album is Logged exactly when the User has given it an Album Score.
- **Rating** — score 0–5 in half-star steps, given to an Album or Song.
- **Album Score** — the Rating a User gives an Album directly; independent of Song Ratings.
- **Review** — free-text opinion by a User on an Album; one per User per Album.
- **Listenlist** — a User's list of Albums to hear later (UI name: "Ouvir depois").
- **Follow** — directed link from one User to another.
- **Feed** — a User's stream of followed Users' recent Ratings.
- **Profile** — a User's public page.
- **Favorites** — a User's 5 all-time favorite Albums and 5 favorite Songs, ordered.
