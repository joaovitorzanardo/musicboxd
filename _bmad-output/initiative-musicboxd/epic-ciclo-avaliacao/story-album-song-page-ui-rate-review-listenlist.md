# Album/Song page UI: rate, review, listenlist

## Description

Builds the Album and Song page UI (per the album.html and musica.html mockups) wiring entries 1 (score), 2 (delete score), 3 (song ratings), 4 (review CRUD+read), and 5 (listenlist add/remove) into the SPA.

## Acceptance Criteria

Verify: From the Album page, a User sets/changes/deletes an Album Score, writes/edits/deletes a Review, and adds/removes it from their Listenlist; from a Song's row, a User rates that Song independently — none of it needs a direct API call.
